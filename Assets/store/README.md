# 🛍️ Store (스토어 / 상점 화면) 에셋 보관 폴더

이 폴더는 인게임 상점(Store / Shop) 화면에 필요한 3D 아이템, 스킨, 패키지 및 상점 UI 배경 에셋을 보관하는 표준 폴더입니다.

## 📁 권장 파일 명명 규칙
- `store_bg.png` : 상점 화면 배경 (1280x720 또는 1920x1080)
- `store_banner.png` : 특별 프로모션 / 패스 배너 (800x240)
- `item_pearl_pack_1.png` : 3D 진주 재화 팩 소형 (512x512, 투명 배경, 테두리/그림자 없음)
- `item_pearl_pack_2.png` : 3D 진주 재화 팩 대형 (512x512, 투명 배경, 테두리/그림자 없음)
- `skin_preview_*.png` : 캐릭터 스킨 3D 미리보기 아이콘
